# 测试说明

## 自动化测试

在项目根目录执行：

```bash
make test
```

测试程序使用临时目录、`tests/fixtures` 测试数据和端口 `18081`。测试结束后临时数据自动删除，不修改 `data/` 下的运行数据。

自动覆盖：

1. 未登录访问控制。
2. 读者和管理员登录。
3. 图书列表。
4. 借书、重复借书。
5. 续借、重复续借。
6. 还书、重复还书。
7. 普通用户越权管理图书。
8. 两名读者同时争抢最后一册。
9. 管理员新增、修改和下架图书。
10. 管理员查询用户、全部借阅和日志。

## 手工验收

- 禁用用户后重新登录应失败。
- 将到期时间改为过去后，记录应显示 `OVERDUE`，并禁止继续借书和续借。
- 下架图书不能新借，但已有记录仍可归还。
- 中断一个客户端不应影响服务器和其他客户端。
- 重启服务器后数据应保留，库存应与有效记录一致。
